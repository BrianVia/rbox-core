  in `src/cli/rbox-paths.ts` already names every daemon runtime directory that

  daemon records disagree about the same workspace. Repo-wide question.

  result are shared `writeFileAtomic`/lock conventions used identically by
  `autostart-cmd.ts`; changing them here alone would diverge from prior art.
